# Security policy

## Supported versions

Security fixes are provided for the latest release on the default branch.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this
repository. Do not open a public issue for a suspected vulnerability.

Include the affected version or commit, reproduction steps, impact, and any
suggested mitigation. You should receive an acknowledgement within seven days.

ScopeWitness is a policy aid, not a security scanner. An aligned result does not
establish that a patch is safe or correct.
